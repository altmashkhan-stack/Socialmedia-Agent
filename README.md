# INSTA 2.0 — Autonomous Multi-Agent Video Studio

A complete, high-craft landing page for **INSTA**, an autonomous multi-agent social video generation platform engineered according to the complete 15-part design specification.

## Overview of Implemented Sections

1. **Announcement bar & navigation:** Slim promotional banner, sticky centered navigation with custom geometric brand mark, resource dropdown, and dark pill CTA button.
2. **Hero:** Pale near-white backdrop, social platform badges (Instagram Reels, TikTok, Shorts), oversized headline with blue gradient emphasis, prompt composer box with quick-action chips, 4 active agent avatars, and a tilted horizontal collage of rounded 9:16 video thumbnails with realistic metrics.
3. **Agent overview:** Numbered section label `01 / AUTONOMOUS SPECIALISTS`, introducing 4 dedicated agents (Scout, Scribe, ReelFX, Pulse) with interactive selection.
4. **Product workspace demonstration:** Split UI container featuring a live research/trends panel on the left, an interactive 4-scene video storyboard on the right, and a dark command bar along the bottom (`/remix-hook`, `/rescript`, `/publish`).
5. **Positioning statement:** Generous breathing-space section with pill badge, two-line value statement, and 4 numbered capability tabs.
6. **Feature section — research:** Two-column layout with copy left, pale-blue interface illustration right, feature checklist, and "done by Agent Scout" attribution.
7. **Feature section — recreate:** Reversed two-column layout with viral link deconstructor UI on left, copy on right, and "done by Agent Scribe & ReelFX" attribution.
8. **Feature section — scheduling:** Copy on left, interactive weekly calendar schedule with dynamic algorithmic peak windows on right, and "done by Agent Pulse" attribution.
9. **Feature section — social listening:** Reversed order with live comment thread and automated DM trigger interface on left, copy on right.
10. **Template library section:** High-density full-width black section with 4 vertical video framework cards, overlay "Remix This Framework" pill buttons, and browse CTA.
11. **Developer & CLI section:** Dark terminal mockup demonstrating the `@insta/agent-cli` execution with copyable command and release metadata.
12. **Comparison section:** Numbered eyebrow `02 / BENCHMARK`, comprehensive comparison table highlighting the INSTA Agents column in pale blue with agent avatars, plus 3 callout benefit cards.
13. **Pricing section:** Sleek black section with monthly/annual billing toggle, 3 pricing tiers (with visually dominant, glowing "Growth Studio" plan featuring agent avatar stack), and enterprise links.
14. **FAQ section:** Split layout with "Questions, answered" heading on the left and an interactive accordion on the right.
15. **Final CTA & footer:** Rounded dark panel with oversized conversion headline, dual action buttons, Product Hunt award badge, 5-column footer, status dot, and large low-contrast "INSTA" watermark.
